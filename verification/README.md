# Verification reports

Reports from independent rebuilds, audits and reruns. Several were written by other Claude sessions acting as builder, independent rebuilder or auditor; they are model output and were checked by rerunning, not taken on trust. Start with the first two.

**Current (v3)**
- `v3_report.md`: per-item status, old vs new numbers, what was not done, conclusion.
- `v3_audit_agent.md`: independent read-only audit of the first v3 fixes (findings and what was fixed).
- `clean_folder_rerun_v3.md`, `clean_folder_rerun_v3_full.md`: clean-folder reruns from fresh pulls (the second covers every step through scripts 28-30).
- `robustness_extra_notes_agent.md`, `bm_replication_notes_agent.md`: notes on the five rerun variants and the book-to-market replication-lite.

**v2 (superseded headline)**
- `spec_v2_compare.md`, `reaudit_v2_agent1.md`, `reaudit_fixes_check_agent3.md`, `review_response_agent3.md`, `audit_checklist_run_agent3.md`: v2 comparison, audits and checklist run.

**v1 (first specification)**
- `data_audit_phase1a_v2.md`, `data_audit_phase2_3.md`, `data_audit_phase4_6.md`, `data_audit_phase7.md`, `data_audit_post_writeup.md`, `data_audit_long_short.md`: data audits by phase.
- `scores_compare.md`, `portfolios_compare.md`, `robustness_compare.md`, `extension_2026_compare.md`, `reit_liquidity_compare.md`, `long_short_compare.md`: independent rebuild comparisons.
- `reaudit_agent1.md`, `reaudit_agent2.md`, `reaudit_agent3.md`: the first re-audit.

The project folder also holds the audit and rebuild scripts and their data; the public repository carries the reports only, some trimmed of company-level values.
